# 📝 Real-Time Collaborative Document Editor

A web-based document editor that allows multiple users to edit documents in real-time. The application features live synchronization, auto-saving, and a Word-like multi-page interface.

---

## 🚀 Features

- ✨ Real-time collaboration using WebSockets
- 💾 Auto-save functionality (every 2 seconds)
- 📝 Rich text editor (Quill.js)
- 📄 Word-style page layout (A4 design)
- ➕ Add multiple pages dynamically (UI-based)
- 🌐 Responsive and clean UI

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- Quill.js (Rich Text Editor)
- Socket.IO Client

### Backend:
- Node.js
- Express.js
- Socket.IO

### Database:
- MongoDB
